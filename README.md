# Автомонтаж видео: шортсы, озвучка, субтитры

Конвейер, который автоматически делает:
- **Из длинного видео** (подкаст, стрим, летсплей): шортсы 9:16 для TikTok/Shorts/Reels
  с вырезанными паузами, субтитрами с подсветкой слов и музыкой + полную версию 16:9 для YouTube;
- **Из текста (.txt)**: готовое вертикальное видео с нейроозвучкой (голоса Светлана/Дмитрий),
  фоном и субтитрами — нужен интернет для голосов Microsoft;
- **Исправление субтитров**: поправь ошибки распознавания в редакторе — ролики перерендерятся.

Распознавание речи — Whisper (на видеокарте NVIDIA, если она есть), монтаж — ffmpeg.
Моменты для шортсов выбирает локальная нейросеть (Ollama), а знаки препинания в
расшифровке восстанавливает Silero — всё работает бесплатно и без интернета.

## Установка на новом компьютере

1. Установи [GitHub Desktop](https://desktop.github.com) (или git) и склонируй репозиторий
   `doublesroses-ai/auto-video-IA` в любую папку.
2. В папке проекта запусти двойным кликом **`setup.bat`** — он сам поставит ffmpeg,
   Python, библиотеки, создаст папки, ярлык на рабочем столе и автозапуск.
3. Готово: кидай файлы в `input/` или открывай ярлык «Автомонтаж видео».

Замечания: на компьютере без видеокарты NVIDIA всё работает на процессоре (медленнее);
для озвучки текста нужен интернет; первая обработка разово скачает модель распознавания речи.

## Как пользоваться

### Приложение с кнопками

Ярлык **«Автомонтаж видео»** на рабочем столе (или файл `Автомонтаж видео.bat` в папке проекта).
В окне: запуск/остановка наблюдателя, обработка видео вручную, озвучка текста,
редактор субтитров и живой журнал происходящего.

### Автоматический режим

1. Наблюдатель стартует сам при входе в Windows (задача «AutoVideoIA Watcher»),
   вручную — кнопкой в приложении или `start_watcher.bat`.
2. Кидай в папку `input/` видео **или текстовый файл .txt** (текст будет озвучен нейроголосом).
3. Забирай результат из `output/<имя файла>/`:
   - `shorts/short_01.mp4`, `short_02.mp4`, ... — вертикальные шортсы (лучший — первый);
   - `<имя>_youtube.mp4` — полная версия 16:9 с субтитрами;
   - `metadata.json` — таймкоды и «крючки» каждого шортса (удобно для описаний);
   - `transcript.json` — полная расшифровка речи.

Обработанные исходники переезжают в `input/done/`, сломавшиеся — в `input/failed/`
(причина — в `logs/errors.log`).

### Ручной режим

```
.venv\Scripts\python.exe make_shorts.py "путь\к\видео.mp4"
```

Полезные флаги: `--shorts 5` (сколько шортсов), `--no-music`, `--no-youtube`.

### Фоновая музыка и фоны

- Музыка: положи mp3/wav в папку `music/` — конвейер сам выберет случайный трек и
  приглушит его, когда звучит речь (сайдчейн-дакинг). Папка пуста — ролики без музыки.
- Фоны для озвучки текста: положи видео в папку `backgrounds/` — для роликов из текста
  будет выбираться случайный фон. Папка пуста — анимированный градиент.

## Настройки — `config.json`

| Ключ | Что делает |
|---|---|
| `language` | язык речи: `"auto"`, `"ru"`, `"en"`, ... |
| `whisper_model` | `"auto"` = large-v3-turbo на GPU / small на CPU; можно задать явно |
| `silence.noise_db` | порог тишины, дБ (-32 по умолчанию; тише порог — режет агрессивнее) |
| `silence.min_silence_sec` | паузы короче этого не вырезаются |
| `shorts.count` | сколько шортсов делать из одного видео |
| `shorts.min_sec` / `max_sec` | длительность шортса |
| `subtitles.uppercase` | СУБТИТРЫ ЗАГЛАВНЫМИ (стиль TikTok) |
| `subtitles.max_words_per_card` | слов на экране одновременно |
| `music.volume` | громкость музыки (0.16 = 16%) |
| `vertical.background` | `"blur"` — размытый фон, `"crop"` — кадрирование на весь экран |
| `render_youtube_version` | делать ли полную версию 16:9 |
| `tts.voice` | голос озвучки: `ru-RU-SvetlanaNeural` или `ru-RU-DmitryNeural` |
| `keep_work_files` | хранить рабочие файлы в `work/` (нужно для перерендера субтитров; можно чистить кнопкой или вручную) |
| `punctuation.enabled` | восстанавливать точки/запятые в расшифровке (Silero, локально) |
| `highlights.ollama_model` | модель Ollama для умного отбора моментов; если Ollama не запущена — работает встроенная эвристика |

## Как это устроено

```
input/видео.mp4
   │ 1. ffmpeg silencedetect — вырезаем паузы (jump cut)
   │ 2. faster-whisper — расшифровка с таймкодами каждого слова
   │ 3. Silero — восстанавливаем точки и запятые в расшифровке
   │ 4. Ollama — нейросеть выбирает цепляющие моменты и придумывает заголовки
   │    (если Ollama не установлена — работают встроенные правила)
   │ 5. ASS-субтитры с караоке-подсветкой + рендер 9:16 (NVENC)
   │ 6. полная версия 16:9 с субтитрами
   ▼
output/видео/
```

Клип всегда заканчивается на границе фразы (по знакам препинания или естественной
паузе в речи) и плавно затухает — обрыва на полуслове не бывает.

## Обслуживание

- Убрать автозапуск: `schtasks /Delete /TN "AutoVideoIA Watcher" /F`
- Логи наблюдателя: `logs/watcher.log`, ошибки: `logs/errors.log`
- Модели Whisper кэшируются в `%USERPROFILE%\.cache\huggingface`
