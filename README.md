# Автомонтаж видео: длинное видео → шортсы

Конвейер, который из длинного видео (подкаст, стрим, летсплей) автоматически делает:
- **Шортсы 9:16** для TikTok / YouTube Shorts / Reels — с вырезанными паузами,
  стильными субтитрами с подсветкой слов и фоновой музыкой;
- **Полную версию 16:9** для YouTube — с вырезанными паузами и вшитыми субтитрами.

Всё работает локально и бесплатно: распознавание речи — Whisper (на видеокарте NVIDIA,
если она есть), монтаж — ffmpeg.

## Как пользоваться

### Автоматический режим (рекомендуется)

1. Запусти наблюдатель двойным кликом: `start_watcher.bat`
   (или настрой автозапуск при входе в Windows: правый клик на
   `setup_autostart.ps1` → «Выполнить с помощью PowerShell»).
2. Кидай видео в папку `input/`.
3. Забирай результат из `output/<имя видео>/`:
   - `shorts/short_01.mp4`, `short_02.mp4`, ... — вертикальные шортсы (лучший — первый);
   - `<имя>_youtube.mp4` — полная версия 16:9 с субтитрами;
   - `metadata.json` — таймкоды и «крючки» каждого шортса (удобно для описаний);
   - `transcript.json` — полная расшифровка речи.

Обработанные исходники переезжают в `input/done/`, сломавшиеся — в `input/failed/`
(причина — в `logs/errors.log`).

### Ручной режим

```
.venv\Scripts\python.exe make_shorts.py "путь\к\видео.mp4"
```

Полезные флаги: `--shorts 5` (сколько шортсов), `--no-music`, `--no-youtube`.

### Фоновая музыка

Положи свои mp3/wav в папку `music/` — конвейер сам выберет случайный трек и
приглушит его, когда звучит речь (сайдчейн-дакинг). Папка пуста — шортсы без музыки.

## Настройки — `config.json`

| Ключ | Что делает |
|---|---|
| `language` | язык речи: `"auto"`, `"ru"`, `"en"`, ... |
| `whisper_model` | `"auto"` = large-v3-turbo на GPU / small на CPU; можно задать явно |
| `silence.noise_db` | порог тишины, дБ (-32 по умолчанию; тише порог — режет агрессивнее) |
| `silence.min_silence_sec` | паузы короче этого не вырезаются |
| `shorts.count` | сколько шортсов делать из одного видео |
| `shorts.min_sec` / `max_sec` | длительность шортса |
| `subtitles.uppercase` | СУБТИТРЫ ЗАГЛАВНЫМИ (стиль TikTok) |
| `subtitles.max_words_per_card` | слов на экране одновременно |
| `music.volume` | громкость музыки (0.16 = 16%) |
| `vertical.background` | `"blur"` — размытый фон, `"crop"` — кадрирование на весь экран |
| `render_youtube_version` | делать ли полную версию 16:9 |

## Как это устроено

```
input/видео.mp4
   │ 1. ffmpeg silencedetect — вырезаем паузы (jump cut)
   │ 2. faster-whisper — расшифровка с таймкодами каждого слова
   │ 3. эвристика «крючков» — выбираем самые цепляющие моменты
   │ 4. ASS-субтитры с караоке-подсветкой + рендер 9:16 (NVENC)
   │ 5. полная версия 16:9 с субтитрами
   ▼
output/видео/
```

## Обслуживание

- Убрать автозапуск: `schtasks /Delete /TN "AutoVideoIA Watcher" /F`
- Логи наблюдателя: `logs/watcher.log`, ошибки: `logs/errors.log`
- Модели Whisper кэшируются в `%USERPROFILE%\.cache\huggingface`
